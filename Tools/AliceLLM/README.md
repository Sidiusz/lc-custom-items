# Опыт: понимание вопроса маленькой LLM

`run.sh модель.gguf [набор] [потоки]` — Qwen2.5-Instruct (gguf) выбирает тему вопроса из intents.txt
(вывод ограничен кодами тем). `RERANK=8` — LLM выбирает только из 8 ближайших по смыслу тем.

Итог 13.10 на 4 ядрах, без видеокарты (наборы из Tools/AliceSemantic/tests):

| вариант | para (112) | hold (62, новые фразы) | ложных | задержка | размер |
|---|---|---|---|---|---|
| слова + смысл (rubert-mini, как в моде) | 112 | 61 | 0–1 | ~10 мс | 68 МБ |
| Qwen2.5 0.5B, все темы | 24 | — | 6/6 | ~300 мс | 470 МБ |
| Qwen2.5 1.5B, все темы | 61 | — | 6/6 | ~550 мс | 1,1 ГБ |
| Qwen2.5 1.5B, из 8 ближайших | — | 46 | 5/5 | ~3,6 с | 1,1 ГБ |

LLM хуже и медленнее: в мод не берём.
