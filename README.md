# CustomItems: каркас мода с кастомными предметами для Lethal Company

Стек: **BepInEx 5** (загрузчик модов) + **LethalLib 1.2.0** (регистрация предметов в игре) + **Unity AssetBundle** (ассеты Item и префабы предметов).

Схема обычная для модов на LethalLib: у каждого предмета есть ассет `Item` игры (название, стоимость, вес, хват, оффсеты) в `Assets/Sources/Data/Items/` и префаб в `Assets/Sources/Prefabs/` (модель, NetworkObject, коллайдер, скан-нода, скрипт поведения со звуками). Всё настраивается в инспекторе Unity. Мод берёт из бандла `ItemRegistry` (список предметов с редкостью и ценой) и регистрирует перечисленные там предметы.

Предметы: Егермейстер, энергетик Adrenaline Game Fuel, монитор 27", игрушечный пистолет (скрап, стреляет пульками из магазина; пачки пулек продаются в терминале), плюшевый Уинстон. Яндекс Колонка (магазин терминала): часы с внутриигровым временем, отвечает на «Алиса, …» голосом, моргает глазами, работает от батареи.

Образец, с которого удобно начинать новый предмет, — монитор: у него нет своего поведения (`Monitor27Item` пустой), всё задаётся в `Data/Items/Monitor27.asset` и `Prefabs/Monitor27.prefab`.

## Структура

Репозиторий одновременно Unity-проект (HDRP, Unity 2022.3.62f2) и C#-проект мода.

```
lc-custom-items/
├── Assets/
│   ├── Sources/                  всё наше в Unity
│   │   ├── Art/
│   │   │   ├── Models/<Предмет>/     fbx/obj (Tools/ пишет сюда)
│   │   │   ├── Textures/<Предмет>/   текстуры и иконки инвентаря
│   │   │   ├── Materials/<Предмет>/  материалы HDRP/Lit
│   │   │   └── Audio/<Предмет>/      звуки
│   │   ├── Prefabs/              префабы предметов (<Предмет>.prefab)
│   │   ├── Data/
│   │   │   ├── ItemRegistry.asset    какие предметы в моде: редкость, магазин, цена
│   │   │   └── Items/<Предмет>.asset ассеты Item: название, стоимость, вес, хват, оффсеты...
│   │   ├── Scenes/               тестовая сцена
│   │   └── Scripts/
│   │       ├── GameStubs/        заглушки Item, GrabbableObject, ScanNodeProperties из игры (без asmdef!)
│   │       ├── Runtime/          HeldItemPreview (asmdef CustomItems.Tools)
│   │       └── Editor/           меню Lethal Company: DLL, создание ассетов, иконки, сборка бандла
│   ├── Plugins/                  DLL игры и мода для редактора (создаётся сама, в .gitignore)
│   └── Settings/                 настройки HDRP (путь задан в ProjectSettings, не переносить)
├── Packages/, ProjectSettings/   Unity
├── Bundles/                      собранный AssetBundle `sidiuszcustomitems` (коммитится)
├── CustomItems/                  C#-проект мода (вне Assets/, Unity его не видит)
│   ├── CustomItems.csproj        плагин BepInEx (SidiuszCustomItems.dll)
│   ├── Plugin.cs                 грузит бандл и регистрирует предметы из ItemRegistry
│   ├── translations/             перевод для русификатора LethalRussian
│   └── Items/                    SidiuszCustomItems.Items.dll: без BepInEx и LethalLib, её грузит и Unity
│       ├── ItemRegistry.cs       тип ассета ItemRegistry
│       ├── CustomGrabbable.cs    база: анимации/звуки из ванили, шейдеры HDRP
│       └── <Предмет>Item.cs      поведение предметов (вешается на префаб)
├── Tools/<Предмет>/              генераторы моделей и текстур (Blender/Python)
└── thunderstore/manifest.json    для публикации на Thunderstore
```

Код мода лежит вне `Assets/` и собирается `dotnet build`. Чтобы Unity знал скрипты предметов, готовая `SidiuszCustomItems.Items.dll` копируется в `Assets/Plugins/SidiuszCustomItems/` (сама, см. раздел 2), а в `Assets/Plugins/Game/` — `Unity.Netcode.Runtime.dll` из папки игры со всем, на что она и мод ссылаются. Сами типы игры, которые хранятся в ассетах (`Item`, `GrabbableObject`, `ScanNodeProperties`, `ItemGroup`), объявлены заглушками в `Assets/Sources/Scripts/GameStubs/`: только поля, без логики. У этой папки нет asmdef (asmdef лежат только в `Scripts/Runtime/` и `Scripts/Editor/`), заглушки компилируются в `Assembly-CSharp` проекта: в бандле они записаны как `Assembly-CSharp::Item` и в игре находят настоящие классы. Класть в Unity `Assembly-CSharp.dll` игры нельзя: для DLL с этим именем Unity не создаёт скрипты, и ассеты сохраняются с «missing script». Скрипты предметов вынесены в отдельную сборку без BepInEx и LethalLib, чтобы Unity мог её загрузить. Остальные скрипты Unity-проекта лежат в asmdef'ах.

## 1. Что нужно установить

- .NET SDK 8 (или новее) — для `dotnet build`.
- Unity 2022.3.62f2 (как у игры). Шаблон Lethal Company не нужен.
- r2modman или Gale с профилем Lethal Company, где стоят **BepInExPack** и **LethalLib**.

## 2. Unity: ассеты предметов и бандл

Порядок важен: сначала мод, потом Unity.

1. Соберите мод: `cd CustomItems && dotnet build -c Release` (раздел 3).
2. Откройте корень репозитория в Unity Hub (Add → Add project from disk).
3. При первом открытии Unity попросит папку игры (где лежит `Lethal Company.exe`) и скопирует из неё нужные DLL в `Assets/Plugins/Game/`. Если окно не появилось или папка поменялась: меню **Lethal Company → Setup → Import Game DLLs**. `SidiuszCustomItems.Items.dll` подтягивается сама, когда вы возвращаетесь в Unity после `dotnet build` (или **Lethal Company → Setup → Update SidiuszCustomItems.Items.dll**).
4. После этого Unity сам создаст недостающие ассеты: `Data/Items/<Предмет>.asset`, `Prefabs/<Предмет>.prefab` и `Data/ItemRegistry.asset`, и пометит их бандлом `sidiuszcustomitems`. Вручную: **Lethal Company → Create Missing Item Assets**. Уже существующие ассеты не перезаписываются, так что правки в инспекторе не пропадут. Ассеты, сохранённые без скрипта (когда DLL не загрузились), пересоздаются.
5. Настраивайте в инспекторе:
   - **ассет Item** (`Data/Items`): Item Name, Is Scrap, Min/Max Value (игра умножает на 0.4), Weight (1.05 = 5 фунтов), Two Handed, Tool Tips, Item Icon, Position/Rotation Offset (в руке), Resting Rotation (на полу), Vertical Offset и всё остальное, что есть у ванильных предметов. Пустые анимации и звуки подбора/броска берутся у ванильного предмета из `Template Item Name` на префабе;
   - **префаб** (`Prefabs`): модель, коллайдер, скан-нода, на скрипте предмета звуки (`Voice Clip`, `Shot Clip`...) и `Template Item Name`;
   - **ItemRegistry** (`Data`): какие предметы попадают в мод, редкость скрапа, продажа в магазине и цена.
6. Меню **Lethal Company → Build AssetBundles**. Бандл окажется в `Bundles/sidiuszcustomitems`, откуда его заберёт сборка мода.

Язык: в ассетах всё по-английски, перевод даёт русификатор **LethalRussian** по файлу `CustomItems/translations/Sidiusz-CustomItems.txt` (мод передаёт его через API LethalRussian, если тот установлен). Строки `@item English=Именительный|винительный|род` (род m/f/n/p) для названий, `English=Русский` для подсказок и сообщений. Меняете английское название или подсказку в Item — поправьте ключ и в этом файле.

Редкость, магазин и цена из ItemRegistry служат значениями по умолчанию для конфига BepInEx (`BepInEx/config/sidiusz.customitems.cfg`), так что их можно поменять и без пересборки. Если в конфиге уже есть строка, она важнее Unity: удалите её, чтобы взялось новое значение.

Иконки инвентаря рисуются сами из модели предмета: `Art/Textures/<Предмет>/<Предмет>Icon.png`, ставятся в поле Item Icon. Перерисовать все (например, после смены модели или материала): **Lethal Company → Render Item Icons**. Иконку, которую вы назначили в Item из другого места, скрипт не трогает.

Защита от спама: у всех предметов между нажатиями ЛКМ есть пауза, по умолчанию 1 с. Своя пауза задаётся полем **Use Cooldown** на префабе (0 = по умолчанию); у егермейстера и пистолета она задана в коде.

Если поменяли модель и хотите собрать префабы заново: **Lethal Company → Rebuild Item Prefabs** (ассеты Item не трогает, ручные правки префабов пропадут). Если поменяли код поведения (новые поля), пересоберите мод и бандл: поля префаба должны совпадать с DLL.

Если материал модели на другом шейдере (например, Standard из импортированной модели), код при появлении предмета переведёт его на HDRP/Lit с той же текстурой и цветом.

### Яндекс Колонка: голосовые команды

Колонка продаётся в магазине терминала за 100 кредитов: `buy alisa` (или `buy yandex`). Цвет каждой выпадает случайно: серая, голубая, розовая или чёрная. Её носят в руках и ставят, просто выбросив (G) на пол или стол. ЛКМ включает и выключает, E — поболтать (случайная фраза). Цвет и включённость сохраняются вместе с кораблём. Включённая колонка тратит батарею: полного заряда хватает на 30 минут, заряжается на зарядке корабля как фонарик. Цвета корпуса в `bodyColors` на префабе.

На экране время, пока колонка молчит, а когда говорит, вместо него глаза: смотрит, улыбается, щурится, подмигивает, косится в стороны, моргает. Слушая вопрос, делает большие глаза.

На корабле колонку можно переставить как мебель: посмотреть на неё, нажать B (клавиша режима строительства), она едет за взглядом по полу, столам и полкам, R поворачивает, B или ЛКМ ставит, Esc или ПКМ отменяет. Ставит хост и рассылает всем. Голос: «Алиса» и вопрос, например «Алиса, какая погода сейчас?». После одного «Алиса» колонка пищит и ждёт вопрос: пока говорят — слушает (до `ListenMax`, 12 с), после `ListenSilence` секунд тишины (3) выключается со звуком. На «Алиса, …» одним духом она всё равно сначала просыпается (сигнал, глаза), потом «думает» случайные `ThinkMin`–`ThinkMax` секунд (0,7–1,5), на экране бегает круг, и только потом отвечает. Пока она слушает, думает, говорит и 20 с после ответа, сама (события вроде «сегодня без Паши») не заговаривает. «Алиса» колонка слышит сразу (через ~0,2 с после конца слова), и дальше ждёт вопрос до `ListenSilence` секунд: тишина, шум, дыхание и «э-э» вопросом не считаются, нужно хотя бы `MinSpeech` секунд речи (0,3), а конец вопроса — пауза `EndPause` (0,8 с). Проснувшись на «Алиса» одного игрока, колонка слушает его: фразы остальных без «Алиса» в это время не вопрос (с «Алиса» — новый вопрос, и колонка переключается на того, кто позвал). Голос каждого игрока приходит к хосту отдельно, поэтому разговор рядом не мешает. Слышит только голосовой чат: при выключенном микрофоне или не нажатой рации (push-to-talk) не реагирует. Пока колонка говорит, новые вопросы она не слушает (кроме «стоп»), включается настройкой `AllowInterrupt`. Распознаёт офлайн хост (Vosk с маленькой моделью vosk-model-small-ru-0.22 для «Алиса» и чернового текста, сам вопрос — Whisper), сразу всех: свой микрофон и голоса остальных, которые и так приходят к нему по голосовому чату. Поэтому колонка понимает любого игрока, а ответ звучит один раз. Слушается только тот, кто ближе 8 м к включённой колонке, у каждого свой поток распознавания. Ответ приходит, как только в начале фразы понятны «Алиса» и вопрос, без ожидания паузы. После каждого шага (позвали, спросили) распознавание начинается заново, а пока колонка думает или говорит, вопросы не слушаются, поэтому фразы не склеиваются. После «поставь», «полетели», «лети» колонка ищет луну, а не друга, и сравнивает куски речи по звучанию («пашу рен с» ≈ «ашуранс»). В лог BepInEx пишется каждая услышанная фраза, выбранная тема, самый похожий пример и его похожесть (строки `[Алиса]`). Вопрос можно задать своими словами: что колонка понимает, записано не в коде, а в `CustomItems/intents.txt` (встроен в DLL) строками «Тема: пример, пример». Вопрос сравнивается со всеми примерами по основам слов (русский стеммер Snowball, «погодой» = «погода»), с одной-двумя опечатками, редкие слова весят больше частых; отвечает тема самого похожего примера, если похожесть не ниже 0,7. Лишние редкие слова в вопросе похожесть снижают («поставь Пашу» уже не «где Паша»): лучше «не поняла», чем ответ не на тот вопрос. Разговор может продолжаться: строка `HowAreYou/Ask > HowAreYou/Good: хорошо, отлично` значит, что после фразы из `HowAreYou/Ask` («Всё отлично, а у вас как?») колонка ждёт ответ без «Алиса» и на похожий отвечает фразой из `HowAreYou/Good` («Здорово!»). Папка `<Тема>/Ask` звучит вперемешку с обычными ответами темы. Так же после анекдота «ещё» — следующий анекдот, «смешно» — `Joke/Laugh`, «не смешно» — `Joke/NotFunny`. Непохожий ответ без «Алиса» колонка пропускает (говорят между собой), с «Алиса» — это новый вопрос. `{name}` в примере — любой друг из `SpokenNames` в любом падеже (падежи колонка строит сама: Паша → Пашей, Пашу; Пашок → Пашка). Новые слова в intents.txt работают без пересборки чего-либо: вопрос пишет Whisper, а имена друзей и луны ему подсказываются. Свои вопросы добавляются строкой в `BepInEx/config/SidiuszCustomItems.intents.txt` (создаётся при первом запуске), например `Joke: насмеши меня, давай прикол` или `#whereis: как там {name}`. Своя тема — папка в `Phrases` и строка с её именем. «Алиса, полетели на Титан», «поставь маршрут на Рен» (`#route`) — колонка сама ставит маршрут, как терминал: только на орбите, если хватает кредитов (списывает цену), луны и цены берутся из терминала, так что и модовые. Ответ: `Route/Done` (иначе `Navigation`), `Route/NoMoney`, `Route/Landed` (корабль не на орбите), `Route/Busy` (уже летим), `Route/Already` (мы уже там), `Route/Unknown` (не поняла луну); без записей — `Refuse`/`Ok`. Как луны зовут вслух — строки `@Titan: титан` в intents.txt, `{moon}` в примере — любая из них. У лун только звучания названий (Assurance — «асуранс», «ашуранс»; Offense — «офенс»; Vow — «вов», «вау»; Experimentation — «экспериментейшн»). Названия лун есть в подсказке Whisper. Куски вроде «асу ранс» в строках остались для своих слов, которых нет в модели: после «поставь», «полетели» колонка склеивает куски и сверяет по звучанию; модовые луны без строки узнаются по транслиту. Фразы из кусков: числа складываются из `Numbers/0…19`, десятков `Numbers/20…90`, сотен `Numbers/100…900` и `Numbers/1000` («тысяча двести сорок»), больше — `Numbers/More1000`/`More2000` («Больше двух тысяч!»); перечисления — через `And` («и») и `And/Also` («и ещё», «а также»). «Сколько на корабле» (`#loot`) — «Всего на корабле» (`Loot/Intro`) и сумма лута, иногда сначала «Смотрю…» (`Wait`). «Который час» — «На часах» (`Time/Intro`) + часы + `Time/Hours/One|Few|Many` + минуты до 5 + `Time/Minutes/Many`; не хватает куска или `TimeInNumbers = false` — словами из `Time/<час>`. «Кто погиб» (`#whodied`) — имена погибших из `Call/<Папка>` через «и». «Андрей жив?», «Андрей умер?» (`#isalive`) — да или нет из `Ball/Yes`/`Ball/No` и где он («Конечно! Андрей где-то в комплексе»), погиб — «Андрей, к сожалению, погиб». «Как меня зовут» — «Вы Андрей» (`Names/<Папка>`) или «Вас зовут» (`MyName/Intro`) + «Андрей!» (`Call/<Папка>`). На «Алиса» без вопроса иногда «Слушаю!» (`Listen`, шанс `ListenVoiceChance`). После анекдота «ещё» — «А вот ещё…» (`Joke/Next`) и следующий. «Включи/выключи свет» (`#lightson`, `#lightsoff`, ответ `Lights/On`, `Lights/Off`). События: вернулся из комплекса на корабль — `Events/Back`, первый — `Events/FirstBack/<Папка>` («О, Андрей! А остальные где?»), без лута — `Events/BackEmpty`, ранен — `Events/BackHurt`; монстр на голове у игрока рядом (блоха, тюльпановая змея) — `Events/Enemy/<имя>/OnHead`. Команды корабля (выполняет хост, как рычаг, кнопки и терминал): «взлетаем», «полетели», «запускай» (`#launch`) — колонка спрашивает `Launch/Confirm` («Вы уверены?») и ждёт ответ без «Алиса»: «да» — дёргает рычаг (на луне взлёт `Launch/Takeoff`, на орбите посадка `Launch/Land`), «нет» — `Launch/Cancel`, другое или тишина — `Launch/NoAnswer` («Не расслышала, не запускаю»), но с шансом 10% `Launch/Anyway` и запускает. Нельзя (корабль летит, рычаг недоступен, дедлайн не в Компании) — `Launch/Busy`. «Закрой двери» / «открой двери» — как кнопки, только на луне и пока двери не перегрелись (`Doors/Closed`, `Doors/Opened`, `Doors/Locked`). «Купи про-фонарик» (`#buy`) — «Сколько?» (`Buy/HowMany`), ответ числом («два», «пару»), без ответа — одну штуку; «купи два фонарика», «купи про-фонарики в количестве трёх штук» — сразу: если есть «купи» и предмет, это покупка при любых лишних словах, число берётся в любом месте и форме («3», «3шт», «трёх», «пару», «парочку», «десяток»). Цена со скидкой магазина, доставка дропшипом, не больше 12 за раз: `Buy/Done`, `Buy/NoMoney`, `Buy/Full`, `Buy/Unknown`. Как предметы зовут вслух — строки `$Pro-flashlight: про фонарик` в intents.txt. Без записей колонка отвечает `Ok`, `Refuse`, `Mumble`. Настройка `HostListens = false` возвращает старый режим, когда каждый распознаёт свой микрофон у себя.

Память разговора (`Items/YandexStationContext.cs`): колонка помнит 2 минуты, о чём говорили (тема, о ком, кто спросил), события последних минут и итоги прошлого дня. Сразу после ответа (`FollowSeconds`, 6 с) она слышит короткий переспрос без «Алиса»: «а Паша?», «а остальные?», «а ты?», «ещё», «почему?» (`Why/<повод>`), «точно?» (перепроверяет по игре), «а сейчас?», «а вчера?», «ты уже говорила», «спасибо». Ответ выбирается под ситуацию, если такой вариант записан: `<Тема>/<Имя>` (кто спросил), `<Тема>/Morning|Day|Evening|Night|Orbit`, `<Тема>/Sad` (сегодня кто-то погиб), `<Тема>/Happy` (квота есть), `<Тема>/Again` (спросили снова); иногда ответ начинается с обращения `Lead/<Имя>`. Три грубости за 5 минут — обижается на `OffendedSeconds` (90 с), пока не извинятся. Новые вопросы по игре: сколько ещё собрать на квоту, сколько до отлёта, здоровье, кто в комплексе и на корабле, что нового, что опасного на луне, мнение о друге, арифметика, монетка, кубик, «кто пойдёт первым», «да или нет». Сама начинает разговор и ждёт ответ: «Куда летим?» на орбите (называют луну — ставит маршрут), «Все на борту. Улетаем?» вечером («да» — дёргает рычаг), «Квота скоро, помните?», «Вы как, держитесь?» после смерти, «Скучаете? Анекдот?», «Вы там не уснули?»; на «взлетай», когда кто-то живой снаружи, — «Не все на борту! Паша… Всё равно взлетаем?». Любое событие со строками `Events/X > Events/Y: …` в intents.txt ждёт ответа само. Фразы из кусков: `Glue/Name/<Имя>` («Паша…») + `Glue/Place/Inside` («…в комплексе.»), числа + `Glue/Unit/Credits` («…кредитов.»); без кусков звучат целые фразы. Полный список диалогов с ветками и список записей — в alice-dialogues.md и alice-missing.txt проекта.

Погода берётся из WeatherRegistry, если он стоит (модовые погоды тоже), иначе из игры. Для модовой погоды можно сделать папку `Weather/<Название погоды>`, без неё колонка отвечает фразой из `Weather/Other`. На лунах с погодой из `JammingWeathers` (по умолчанию `Solar Flare`) колонка сбоит: на экране `Err`, на любой вопрос фраза из `Error`.

События: колонка изредка говорит сама, когда что-то происходит, и её слышат монстры (слепая собака прибежит на «какая милая собачка»). Решает хост, фразы лежат в `Phrases/Events/<Тема>`: `Landed`, `Leaving`, `PlayerDied`, `Night`, `PickedUp`, `LowBattery`, `Idle` и `Enemy/<enemyName монстра>` (`MouthDog`, `Flowerman`, `Spring`, `Crawler`...; имя для нового монстра пишется в лог при первой встрече). Тема без фраз молчит. Шанс, паузы, радиус и громкость в секции `[Yandex Station Events]` конфига.

Ещё темы: `Numbers/0` … `Numbers/10` — из них собирается ответ на «сколько нас» (`Count/1`, `Count/2`, `Count/3`, `Count/Many`, иначе число). `Goodbye` — на «пока», «до свидания». `Repeat` — тот же вопрос второй раз за минуту, с шансом `RepeatChance` (50%), иначе отвечает заново. `Events/NewGame` («Привет, новички!») — один раз всем, когда зашли в игру. События `Events/Money` (выросли кредиты, продали скрап), `ManyItems` (на корабле 20+ скрапа), `Work` (занесли скрап), `Drink` (рядом отпили энергетик или Егермейстер), `Music` (рядом играет бумбокс), `Suit` (кто-то рядом сменил костюм), `Walkie` (рядом включили рацию), `LateDay` (день к концу), а `Count/<N>` — когда рядом с колонкой стало больше людей.

`Time/<час>` (0–23) — время целой фразой («Три часа дня»), `Time/Almost/<час>` — «Почти семь»: после половины часа колонка говорит следующий час, сначала «почти»; нет записи на час — ближайший записанный час; цифрами время не звучит никогда, без единой записи часа — `TimeError`. `TimeError` — «который час» на луне со сбоем. `Game/Ask` — на «давай поиграем», потом 10 секунд любой ответ без «Алиса» получает `Game/Unknown`. `Love` — «ты меня любишь», `Refuse` — «сделай», «принеси», «помоги»…, `Ok` — «хорошо», «ладно» и фразы с «я»/«мы». Событие `Events/Winston` (рядом Уинстон или им пищат).

Друзья по нику Steam: таблица `Names` в секции `[Yandex Station]` конфига, «ник,ник=Папка» через `;`. На «Алиса, как меня зовут?» колонка говорит фразу из `Names/<Папка>` (незнакомому — `Names/Unknown`), а когда умирает знакомый игрок, сначала пробует `Events/PlayerDied/<Папка>`. Ники сравниваются без регистра и значков, `Sidiusz*` подходит к `Sidiusz`.

«Какой заряд» — `Battery/0` … `Battery/100` (по 10%) или словами `Battery/Full`, `AlmostFull`, `MoreHalf`, `LessHalf`, `AlmostEmpty`. «Какого ты цвета» — `Color/Grey`, `Blue`, `Pink`, `Black` по корпусу, иначе ближайший (`White` для серой, `DarkBlue` для голубой). На «сделай», «хочешь» колонка вперемешку отвечает `Agree` («Хочу!») и `Refuse` («Не хочу»). При выключении и разряде — только звук выключения. Болтовня без повода (`Events/Idle`) выключена по умолчанию (`IdleSeconds = 0`). Событие `Events/LeftBehind` — все отошли от колонки.

«Алиса, кто я?» — роль друга из `Roles/<Папка>` по той же таблице ников (без папки — имя из `Names`). «Кто тут», «кто здесь», «кто ты» — `ItsMe` («Это я!»), «кто это», «кто виноват» — `ItsYou` («Это вы!»). Розовая колонка на «какого ты цвета» говорит `Color/Pink`, иначе `Color/Purple`.

Смерть: через пару секунд после гибели колонка может назвать убийцу из `Events/DeathCause/<Враг>/One` (погиб один, «его») или `/Many` (несколько разом, «их»); без этих папок звучит `Events/DeathCause/<Враг>`. Враг — ближайший к телу монстр, его `enemyName` без пробелов (`MouthDog`, `Flowerman`, `ForestGiant`, `BushWolf`, `Spring`, `BaboonHawk`…), никого рядом — `Events/DeathCause/Unknown`. `Events/AllDead` — погибли все, `Events/ForgotSomeone` — корабль улетает, а кто-то живой остался снаружи. «Алиса, есть враги?» / «тут опасно?» — `EnemiesNear`, если в радиусе событий есть живой монстр, иначе `AllClear`. «Мне скучно» — `Game/Bored` («Может, поиграем тогда?»), после него, как после `Game/Ask`, 10 секунд ждёт ответ.

Записи каждой темы звучат по кругу в случайном порядке: пока не прозвучат все, ни одна не повторится. Иногда (`WhimChance`, 15%) колонка капризничает вместо ответа: «Нет связи с сервером» (`Error`), `Refuse`, `Mumble` или `Unknown`. События по умолчанию редкие: шанс 0.2, пауза 90 с, та же тема не чаще раза в 10 минут, болтовня раз в ~4 минуты (старые значения по умолчанию в конфиге заменяются сами).

Разговор (`YandexStationTalk.cs`, все ветки — в списке диалогов). На «Алиса» колонка просыпается сразу, по куску фразы. Позвали и молчат — через раз «Это вы мне?» (`Wake/Ask`), «нет», «не тебе» — `Wake/NotMe`, «да» — «Слушаю». «Ты тут?» — `Here`. Вернулся на корабль после 20 с снаружи — встречает по имени (`Call/<Имя>` + `Events/Back`), один, а кто-то ещё гуляет — `Events/FirstBack/<Имя>` («А остальные где?»), двое — имена через «и» + `Back/Others`, и ждёт ответ: «умерли» — проверяет, кто погиб, «не знаю» — говорит, где они, другое — «Понятно». «Сегодня без Андрея?» тоже ждёт ответ. «Где Андрей», а его нет в игре — `WhereIs/NotHere`, на корабле — `WhereIs/Ship/One|Many`. «Где я» — `WhereIs/Me/Ship|Inside|Outside` или «Вы заблудились?» и ведёт. «Я уже отвечала» — только на вопросы с неизменным ответом (таблица `RepeatTopics`), анекдот ещё раз — следующий анекдот. Темы `Best`, `Math`, `Food`, `Advice`, `Smart`, `Alive`, `Age`, `Company`, `Scared`, `Leave`. «Ты обиделась?» — `Hurt/Yes` (ругали за 3 минуты) или `Hurt/No`. «Скажи привет Паше» — `Call/<Имя>` + `Hello`, «позови Пашу» — `Call/<Имя>` громко + `CallName`. «Сколько я принёс?» — `Earned/Intro` + сумма за день (+ `Earned/Best`), `Earned/None`; «кто больше всех принёс?» — `Earned/BestIs` + имя. «Сколько денег?» — `Credits/Intro` + число. «Расскажи про луну» — `Moon/About/<Луна>`. Через минуту после смерти иногда `Events/Memorial[/<Имя>]`. «Взлетай, взлетай!», «погнали погнали» (команда на взлёт дважды в одной фразе) — без «Вы уверены?», сразу `Launch/Hurry`.

Комплекс и прочее (`YandexStationMore.cs`). «Открой дверь бэ четыре», «отключи турель а два», «выключи мину эм пять» (`#code`): код как в терминале (буква по-русски или латиницей, цифра), колонка делает то же, что терминал: `Door/Try` («Сезам, откройся!») и `Door/Done` («Та-дам!»), кода нет на карте — `Door/NotFound`, не вышло (перезарядка, нет питания) — `Door/Fail/Door|Turret|Mine`; похожие на слух буквы (бэ/дэ/вэ/пэ) сверяются с кодами на карте. «Открой дверь» без кода внутри комплекса — только диалог, обычные двери колонка не открывает: делает вид, что пытается (`Door/Try` и `Door/Fail/Door`, «Я попробовала, не получилось»), или «Дверь закрыта. Нужен ключ. У вас ключ есть?» (`Door/Locked`, `Door/NeedKey`, `Door/AskKey`, на «нет» — `Door/NoKey/Me`). «Где выход», «выведи меня» (`#navexit`), «найди корабль» (`#navship`): колонка ведёт по навигационной сетке, каждые `NavSeconds` (4 с) подсказывает следующий поворот: `Nav/Left|Right|Up|Down`, `Nav/Forward/1|2|3|Many|Short` и `Nav/Back/…`, «а затем» (`Nav/Then`), далеко прямо — «Идите вперёд, пока я не скажу стоп» (`Nav/Go`) и потом `Nav/Stop`, прошли мимо — `Nav/TooFar`, стоят — `Nav/More`, рядом выход — `Nav/Exit/<сторона>`, дошли — `Nav/Arrived/Exit|Ship` и `Nav/Done`, пути нет — `Nav/Fail`, «стоп» — `Stopping`. Один в комплексе дольше 4 минут — «Вы заблудились?» (`Nav/Lost`), на «да» ведёт к выходу. «Что у меня в руке» / «что у него в руке» (`#inhand`) — `Hand/You|Him` + `Hand/<itemName>` или `Hand/Unknown`. «Просканируй луну» (`#scanmoon`) — «Просканировала! На луне примерно» + число + «предметов» + «на сумму» + сумма (`Sum`, больше 2000 — «пяти тысяч» из `Numbers/Gen/<N>` и `Numbers/Thousand/Gen`) + «Они дорогие» (`Scan/…`), или коротко `Scan/Many`, `Scan/Cleared`. «Сколько на корабле» иногда — «На корабле» + N предметов на сумму и «Ого, да вы богаты!» / «маловато» (`Loot/High|Low`, по остатку квоты). «Какая квота» — «Текущая квота» + сдано, «Необходимая квота» + нужно. «Повтори» (`#repeat`) — «Повторяю» и последняя фраза, иногда «Вы хотите, чтобы я повторила?». «Помяукай» — `Meow` или `Meow/Cant`, `Meow/Ask` («Теперь вы помяукайте!») ждёт «мяу» — `Meow/Good`; «мяу» — `Kitty`. «Кто такой Сигурд» — `Sigurd`, «зови меня …» — `CallMe/Forgot|Refuse`, «включи/выключи музыку» — включает бумбокс рядом (`Music/On`, `Stopping`), без бумбокса — `Music`. Покупка с числом иногда: «Заказала! В количестве двух» (`Count/Intro`, `Count/Gen/<N>`). Включение — через раз «Включаюсь» (`TurnOn`). «Алиса» три раза подряд — «Вы чего кричите?» (`Shout`). События: `Events/Mine`, `Events/Mine/Pressed`, `Events/Turret`, `Events/Steam`, `Events/Inside`, `Events/Inside/Dark`, `Events/Inside/Flashlight|NoFlashlight`, `Events/Behind` (монстр за спиной у того, кто держит колонку), `Events/Abandoned` (лежит одна вне корабля `AbandonedSeconds`, 60 с, или корабль улетает без неё), `Events/Dropped` (уронили с высоты, говорит чаще остального), `Events/HalfBattery`, `Events/Charged`, `Events/Fall`, `Events/Teleported`, `Events/Weird` (садятся-встают), `Events/Scan` (хост сканирует рядом), `Events/DoorsClosedOutside`, `Events/Company`, `Events/Sold`, `Events/Fired`, `Events/Eclipse`, `Events/LeftBody/One|Many` (улетают, тела на луне), `Events/Fight` (ударили на корабле без монстров), `Events/Teamkill` (убили своего; ответ «случайно» — `/Accident`, «заслужил» — `/Deserved`, другое — `/Excuse`), `Events/Met/Flowerman|Spring|Bug` (монстра впервые отсканировали или он кого-то убил), `Events/Hold/Shotgun|Toy gun|Gun`, `Events/Shot`, `Events/HiveOnShip`, `Events/Drink/Jagermeister`, `Events/Drink/Alcohol[/<Папка>]`, у кого кончились фонарики — «У вас кончились фонарики. Хотите, закажу?» (`OutOf/…`, на «да» покупает по фонарику на каждого). Одни и те же записи звучат и в других подходящих темах: таблица `Reuse` в `YandexStationMore.cs` («тема ← запись»), например «Я попробовала, не получилось» из `Error` звучит, когда не открылась дверь.

«Алиса, громче / тише / прибавь / убавь» — громкость шагом 10% (от 10% до 100%), без слов: короткий сигнал уже новой громкостью и на пару секунд проценты на экране; «какая громкость» — только показать. Громкость общая для всех и сохраняется вместе с кораблём.

«Кто ты» — `WhoAreYou` (без папки `ItsMe`), «что ты умеешь» — `Skills`, обзывают («дура», «тупая»…) — `Insult`, а сразу после отказа `Refuse` — `Sorry`; «извинись» — тоже `Sorry`. «Замолчи», «тихо», «заткнись» — `Shush`, после неё колонка минуту (`ShushSeconds`) не говорит сама; «стоп» и «хватит» просто обрывают. Вопрос есть, но ни одного слова не разобрано — `Mumble` вперемешку с `Unknown`. «Куда идти», «как пройти» — `Navigation`, «скоро?», «долго ещё?» — `Almost`. На «давай поиграем» и от скуки (`Events/Idle`) иногда `Game/Rend` и сразу `Game/Cancel`. «Где он / где все / где Андрей» — `WhereIs/AFK` (стоит на месте полминуты), `WhereIs/Inside/One|Many` (в комплексе), `WhereIs/Lost/One|Many` (снаружи дальше 40 м от всех), иначе `WhereIs/AllAlive`; друга нет в игре — `Events/Missing/<Папка>`. Друга можно назвать в любой форме и без «где»: «чё с Пашей?», «Пашка умер?», «Сеня жив?». Имена вслух задаёт `SpokenNames` — начала слов («Pavel=паш,павел,павл;…»); погибший друг — `Events/PlayerDied/<Папка>` или его `Events/DeathCause/<Враг>/One`. События: `Events/Joined` и `Events/Joined/<Папка>` (подключился), `Events/Missing/<Папка>` (в игре кроме хоста есть ещё кто-то, 20 секунд никто не приходит, а друга нет; про каждого один раз до посадки и ещё раз после каждой посадки, на все колонки сразу; кто заходил, про того не говорит), `Events/Flashlight` (дёрнули рычаг), `Events/Delivery` (сели, а заказ в пути), `Events/DeliveryMissed` (доставка улетела нераскрытой), `Events/Purchase` (кредиты потратили), `Events/Junk` (на корабле 8+ предметов дешевле 20), `Events/Panic` (погибли несколько разом или подошёл монстр), `Events/Gore` (рядом тело), `Events/LowHealth` (у игрока рядом 30 HP и меньше), `Events/Takeoff` (корабль взлетает).

«Какой твой любимый цвет» — случайная фраза из `FavoriteColor` и всех `Color/*` (на «какого ты цвета» по-прежнему цвет корпуса). `Events/Horn` — рядом дунули в клоунский рожок или воздушный горн. `Events/Suit` звучит и при переодевании, и на «как я выгляжу», «как тебе мой костюм».

«Куда полетим?», «куда летим?», просто «куда?» — случайная фраза из `Moon` («Давайте полетим на Титан!»), только в ответ на вопрос, сама колонка луну не предлагает. Тем, которых нет (например, `Events/Enemy/<монстр>` без записей), колонка просто молчит, а погода без своей папки берётся из `Weather/Other`.

Настройки в секции `[Yandex Station]` конфига: `VoiceCommands`, `WakeWord`, `HearingRadius`, `ListenSilence`, `ListenMax`, `ThinkMin`, `ThinkMax`, `AllowInterrupt`, `JammingWeathers`, `OnlyKnownPhrases` (распознавать только фразы из intents.txt, по умолчанию выключено), `ExtraPhrases`.

| `Time` | «который час» (во время ответа на экране остаётся время) |
| `Greeting`, `Thanks`, `HowAreYou`, `Joke`, `Music` | «привет», «спасибо», «как дела», «расскажи анекдот», «включи музыку» |
| своя папка с русским названием, например `расскажи про компанию` | когда эта фраза есть в вопросе |

«Стоп», «хватит», «замолчи» обрывают ответ.

Распознавание лежит рядом с DLL мода: `Vosk.dll` и папка `vosk/` (нативные библиотеки Windows x64 и модель `model-ru`). Модель — vosk-model-small-ru-0.22 без языковой модели: вместо неё список слов `words.json` как грамматика Vosk (около 60 МБ, Apache 2.0, ужимает `Tools/YandexStation/model/small-gr.py`), лежит в репозитории, `CustomItems/Vosk/model-ru`; `dotnet build` кладёт её в папку сборки и в `PluginDir`. Раньше там была своя модель на большой акустике vosk-model-ru-0.42 (`Tools/YandexStation/model/build.sh` собирает её до сих пор), но у большой акустики слова появляются на 1,5–2 с позже, чем сказаны, а точный текст вопроса всё равно даёт Whisper.

Вопросы колонка понимает и по смыслу, а не только по словам: «сколько у нас бабла» = «сколько денег», «кто-нибудь откинулся» = «кто умер». Это `CustomItems/AliceSemantic.cs`: маленькая русская модель [rubert-mini-frida](https://huggingface.co/sergeyzh/rubert-mini-frida) (MIT, 68 МБ, лежит в репозитории, `CustomItems/AliceSemantic/`) считает вектор смысла вопроса и сравнивает с примерами intents.txt и текстами записей; работает через llama.cpp (`llama.dll` из пакета `LLamaSharp.Backend.Cpu`) на процессоре, около 5 мс на вопрос. При первом запуске векторы примеров считаются в фоне (пара секунд) и кешируются в `BepInEx/cache`. Совпадение по словам по-прежнему главное; смысл подключается, когда по словам не нашлось или нашлось слабо. `dotnet build` кладёт всё в папку `alice-semantic/` рядом с DLL. Нужен Microsoft Visual C++ Redistributable 2015–2022 x64 (есть почти у всех; без него Алиса понимает только по словам). Выключить — `UnderstandMeaning = false` в конфиге. Проверка на своих вопросах — `Tools/AliceSemantic/run.sh`.

Фразы, обращённые к колонке («Алиса, …» и ответы на её вопросы), ещё раз распознаёт **Whisper** (whisper.cpp, модель `ggml-small-q8_0`): он понимает любую речь, а не только слова из intents.txt. Vosk остаётся для мгновенного «Алиса» (колонка просыпается сразу) и запасным вариантом: если Whisper не загрузился, не успел за `WhisperTimeout` секунд или написал мусор, колонка отвечает по тексту Vosk. Всё лежит в папке `whisper/` рядом с DLL: `vulkan/` (видеокарта любого производителя, нужен драйвер с Vulkan), `cpu/` (нативные библиотеки из NuGet-пакетов Whisper.net.Runtime 1.9.1) и модель (264 МБ). Модели в репозитории нет: `dotnet build` качает её с Hugging Face в `CustomItems/obj/whisper/` (один раз, сверяет SHA-256), без сети — только предупреждение (`-p:WhisperDownload=false` — не качать). Настройки: `WhisperRecognition`, `WhisperGpu`, `WhisperTimeout`. Сравнить Vosk и Whisper на тестовых фразах — `Tools/YandexStation/whisper/run.sh`.

## 2.1. Как предмет держится в руке: превью в Unity

В игре предмет каждый кадр ставится в точку руки персонажа и сдвигается на Position / Rotation Offset из его ассета Item. Компонент `HeldItemPreview` (`Assets/Sources/Scripts/Runtime/`) делает в редакторе то же самое, так что оффсеты можно подобрать на глаз.

1. Рипните игру AssetRipper'ом (Export → Unity project) и откройте экспорт отдельным проектом **или** скопируйте модель игрока с нужными мешами, анимациями и аватаром в `Assets/_Ripped/`. Эта папка в `.gitignore`: ассеты игры в репозиторий не кладём.
2. Поставьте в сцену префаб игрока. В иерархии найдите поиском `ItemHolder`: `LocalItemHolder` — рука в виде от первого лица (руки без тела), `ServerItemHolder` — рука на полной модели, как вас видят друзья. Проверьте оба.
3. Поставьте в сцену модель своего предмета (обычный экземпляр, не префаб-ассет).
4. Создайте пустой объект, повесьте на него `HeldItemPreview`, укажите `Holder`, `Item` и `Item Asset` (ассет из `Data/Items`). Кнопка **Взять из Item** подставит текущие оффсеты.
5. Чтобы увидеть позу руки, выделите модель игрока, откройте окно Animation и выберите клип удержания предмета. Анимацию, которую игра включит для вашего предмета, берём у ванильного шаблона из `Template Item Name` на префабе (по умолчанию ванильная Rubber Ducky). Её имя есть в поле `grabAnim` рипнутого ассета этого предмета.
6. Крутите `Position Offset` / `Rotation Offset` в инспекторе, затем нажмите **Записать в Item** и пересоберите бандл.

Для сравнения удобно открыть рипнутые ассеты Item ванильных предметов похожего размера: у них видно, какие оффсеты подобрали разработчики.

`Resting Rotation` — как предмет лежит на полу: игра берёт из него наклон по X и Z, а поворот по Y остаётся случайным. Обычно хватает подобрать, при каком повороте модель лежит естественно.

Финальную проверку всё равно делайте в игре: если что-то чуть съехало, значения можно поправить на лету через UnityExplorer (`itemProperties` предмета → `positionOffset` / `rotationOffset`), а потом перенести в ассет Item.

## 2.2. Настройка предметов прямо в игре

Окно, где на лету меняется, как предмет держится в руке, как лежит на полу и какого он размера.

1. В `BepInEx/config/sidiusz.customitems.cfg` в секции `[Item tuner]` поставьте `Enabled = true`. Клавиша по умолчанию F8, меняется там же (`Key`).
2. В игре нажмите F8. Пока окно открыто, мышь свободна, а камера, ходьба, скан и действия с предметом выключены, так что клики ничего не активируют.
3. Возьмите предмет мода в руку, он выберется сам (или кнопкой вверху окна).
4. Вкладка **В руке**: смещение (Position Offset) и поворот (Rotation Offset). Кнопки −/+ и ±90 крутят предмет вокруг его собственных осей, в поле можно вписать угол. Мышью прямо в мире: ЛКМ — крутить, Ctrl+ЛКМ — двигать, с Shift точнее.
5. Вкладка **На полу**: кнопка «Выбросить из рук», затем наклон (Resting Rotation X/Z, поворот по Y игра выбирает сама) кнопками, пресетами «Стоя / На боку / Лёжа на спине / Вверх дном» или ЛКМ в мире. Окно показывает, на сколько сантиметров низ предмета висит над полом. «Поставить на пол» подбирает Vertical Offset так, чтобы низ касался пола; по умолчанию это происходит само после каждого поворота.
6. **Размер**: множитель к масштабу префаба.
7. **Сохранить** пишет значения в `BepInEx/config/SidiuszCustomItems.tuning.txt`, при запуске они накладываются поверх ассетов. **Отменить правки** — последнее сохранённое, **Как в ассете** — значения из Unity (и убирает предмет из файла). **Скопировать значения для ассета Item** кладёт числа для Item и Scale префаба в буфер обмена и в лог.

Пивот всех префабов в нижней точке модели (его ставит `ItemAssets` при сборке), поэтому у стоящего предмета Vertical Offset около нуля.

Файл настроек действует только на компьютере, где он лежит. Чтобы у друзей предмет выглядел так же, перенесите значения в ассет Item и префаб в Unity и пересоберите бандл.

## 3. Сборка

```bash
cd CustomItems
dotnet build -c Release
```

Пакеты BepInEx и Unity берутся из фида `nuget.bepinex.dev`, он уже прописан в `.csproj`. Результат: `bin/Release/netstandard2.1/SidiuszCustomItems.dll`, `SidiuszCustomItems.Items.dll`, папка `translations` и `sidiuszcustomitems`. Бандл берётся из `Bundles/`, поэтому после изменений в Unity сначала **Build AssetBundles**, потом `dotnet build`.

Чтобы после каждой сборки файлы сами копировались в профиль r2modman:

```bash
dotnet build -c Release -p:PluginDir="C:\Users\<вы>\AppData\Roaming\r2modmanPlus-local\LethalCompany\profiles\Dev\BepInEx\plugins"
```

(в r2modman путь профиля: Settings → Browse profile folder).

## 4. Проверка в игре

1. В папке профиля должно быть `BepInEx/plugins/SidiuszCustomItems/`: `SidiuszCustomItems.dll`, `SidiuszCustomItems.Items.dll`, `Vosk.dll`, `sidiuszcustomitems`, `translations/` и `vosk/`.
2. В `BepInEx/config/BepInEx.cfg` включите консоль: `[Logging.Console] Enabled = true`.
3. Запустите игру через r2modman. В консоли должно быть `CustomItems 0.1.0 загружен` и никаких ошибок про AssetBundle или модель.
4. Быстрый тест без поиска по карте: поставьте `InShop = true` в `BepInEx/config/sidiusz.customitems.cfg` (секция с названием предмета, например `[Winston plush]`), купите его в терминале (`buy winston plush`, с LethalRussian и по-русски). Либо поставьте Imperium и заспавните предмет через его меню.
5. Для теста как скрапа поднимите `Rarity` (например, 200) и слетайте на любую луну.
6. Мультиплеер: проверьте с другом или двумя копиями игры (LAN-режим), что писк слышен второму игроку. У всех игроков мод должен быть одинаковой версии.

## 5. Как добавить новый предмет

1. Файлы в `Assets/Sources/Art/{Models,Textures,Materials,Audio}/<Предмет>/`. Генератор модели, если есть, в `Tools/<Предмет>/`.
2. Класс поведения `MyItem : CustomGrabbable` в `CustomItems/Items/`. Переопределяйте `ItemActivate` (ЛКМ), `Update`, `EquipItem`, `PocketItem`, `DiscardItem` и т.п. Если делать ничего не нужно, пустой класс. Звуки делайте публичными полями `AudioClip`: они появятся в инспекторе префаба. Соберите мод и вернитесь в Unity.
3. Ассеты, вариант А (руками, как в любом моде): Create → Item (ассет в `Data/Items`), префаб в `Prefabs` с моделью, `NetworkObject`, `BoxCollider`, `Rigidbody` (Is Kinematic), `AudioSource`, дочерним `ScanNode` (`BoxCollider` Is Trigger + `ScanNodeProperties`) и вашим `MyItem` (в Item Properties ваш Item). В Item укажите Spawn Prefab. Добавьте строку в `ItemRegistry`. Item и префаб пометьте бандлом `sidiuszcustomitems`.
4. Вариант Б: добавьте описание в таблицу `Specs` в `Assets/Sources/Scripts/Editor/ItemAssets.cs` и нажмите **Lethal Company → Create Missing Item Assets**, он сделает всё из пункта 3.
5. **Build AssetBundles**, потом `dotnet build`.

Тег `PhysicsProp` и слои `Props` / `ScanNode` мод ставит сам при загрузке, в Unity их заводить не нужно. Хеш NetworkObject тоже задаётся модом из имени префаба, так что не переименовывайте префабы между версиями, на которых играете вместе.

Если предмету нужна своя сетевая логика (`[ServerRpc]` / `[ClientRpc]`), понадобится ещё **NetcodePatcher**, он патчит DLL после сборки. Для простых шуток (звук, анимация, шум по ЛКМ) хватает встроенной синхронизации (`Sync Use Function` в Item).
